# PremiAí · página de convite

Página pública que abre os links de convite do app PremiAí: `https://arthurmarques93.github.io/premiai/?e=CODIGO`.
Mostra o nome do evento e o código, com o botão para abrir o app (`premiai://evento/CODIGO`) e o download do Android.
